Setup

Running in under a minute

No installers, no bundled runtimes, no account required. Just download, launch, and play.

1

Download the archive

Grab the latest RequiemTrainer.zip from the release page and extract it to any folder outside your game directory.

2

Launch the game, then the trainer

Start Resident Evil Requiem and load into a save. Run RequiemTrainer.exe as administrator so it can attach to the process.

3

Toggle features with hotkeys

Use the on-screen panel or the default F1–F8 bindings. Every module shows a live active indicator and can be rebound.

Questions

Frequently asked

Is Requiem Trainer safe to run on my PC?
The trainer is fully open source, so every line can be reviewed on the repository. It performs read/write memory operations on the game process only, ships no installers, and makes no network calls. Antivirus tools occasionally flag trainers generically — that is a heuristic, not a detection of malicious code.
Will it work with the Steam and Epic versions of Resident Evil Requiem?
Yes. The trainer detects supported game builds on Windows 10 and 11 regardless of storefront. After a game patch, offsets may need an update — check the release notes for the build number the current version supports.
Can I use it in online or co-op modes?
No. The trainer is intended for single-player offline use only. Do not enable it in any multiplayer, leaderboard or cloud-save sync scenario. Using it online can get your account restricted, and the project does not support that use case.
How do I rebind hotkeys or fix a feature that stopped working?
Open the settings tab in the trainer panel and click any binding to remap it. If a module silently stops working after a game update, download the newest release from gitscore.cc — offsets are refreshed with each supported patch.
